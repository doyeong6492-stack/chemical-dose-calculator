약품 투입량 계산기 v1

설치: ZIP 압축을 풀고 모든 파일을 같은 GitHub Pages 저장소 최상위 폴더에 업로드하세요.
주소 예시: https://계정.github.io/chemical-dose-calculator/
설치/오프라인: HTTPS GitHub Pages에서 최초 접속 후 PWA 설치 가능. 최초 다운로드에는 인터넷이 필요합니다.
입력값: 이 기기의 localStorage에만 저장되며 브라우저/PWA 사이트 데이터를 삭제하면 함께 삭제됩니다.

계산 기준(사진 속 현장 수식과 대조한 잠정식):
응집제 L/min = (원수+회수유량 m3/h) × ppm ÷ 60000
응집제 mL/10초 = (원수+회수유량 m3/h) × ppm ÷ 360
염소 kg/h = (원수+회수유량 m3/h) × ppm ÷ 1000
차염 L/h = (원수+회수유량 m3/h) × ppm ÷ 120 (차염 유효염소 12%, 밀도 1kg/L 가정)

주의: 현장 약품의 실제 규격, 농도/밀도, 계측 단위 및 운전 기준을 확인한 뒤 사용하세요.
이 앱은 SCADA 값과 비교하기 위한 보조 계산기이며 자동운전/설비 제어 기능이 없습니다.
